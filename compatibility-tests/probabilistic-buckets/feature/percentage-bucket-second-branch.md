# Percentage Bucket Picks the Second Branch

The same three-branch percentage bucket as the first-branch test, with a
different seed whose draw lands in the second branch's slice. Only the second
branch's text shows; the first and third branches leave no trace.

```cuentitos
I visit the street market.
  (50%) A food vendor calls out to me with a friendly wave.
  (30%) A street musician plays a quiet, wandering tune.
  (20%) A vendor argues loudly with a customer nearby.
```

s
