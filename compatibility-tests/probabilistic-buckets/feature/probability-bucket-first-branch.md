# Probability Notation Bucket Picks the First Branch

The same bucket shape as the percentage tests, written with probability
notation (`0.5`/`0.3`/`0.2`) instead of percentages. A draw landing in the
first branch's slice shows only that branch's text.

## Script
```cuentitos
I visit the street market.
  (0.5) A food vendor calls out to me with a friendly wave.
  (0.3) A street musician plays a quiet, wandering tune.
  (0.2) A vendor argues loudly with a customer nearby.
```

## Input
```input
seed 6947113883557504045
s
```

## Result
```result
START
I visit the street market.
A food vendor calls out to me with a friendly wave.
END
```
