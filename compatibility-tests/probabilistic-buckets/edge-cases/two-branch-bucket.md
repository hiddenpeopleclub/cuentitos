# Minimal Two-Branch Bucket

The smallest possible bucket has exactly two branches. This behaves the same
as any larger bucket: the draw picks exactly one branch, and the other
leaves no trace.

## Script
```cuentitos
I flip a coin.
  (50%) It lands heads.
  (50%) It lands tails.
```

## Input
```input
seed 6947113883557504045
s
```

## Result
```result
START
I flip a coin.
It lands heads.
END
```
