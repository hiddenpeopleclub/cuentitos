# Edge Case: 100% Is Always Shown

`(100%)` is the percentage-notation upper bound: valid, and the roll always
lands under it, so the line always shows, for any seed.

## Script
```cuentitos
You find a quiet bench.
(100%) A solitary figure sits on the bench, reading.
This serene oasis calms you.
```

## Input
```input
seed 1
s
```

## Result
```result
START
You find a quiet bench.
A solitary figure sits on the bench, reading.
This serene oasis calms you.
END
```
